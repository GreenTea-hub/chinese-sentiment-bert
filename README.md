# chinese-sentiment-bert

《人工智能导论》课程设计作业 —— 基于预训练语言模型的文本分类与方面级情感分析系统（文本情感分析系统）

人工智能导论课程设计作业-文本情感分析系统，由**曾理、谢嘉辉、王文挺、邱润峰**四人共同完成。

## 项目简介

本项目选题为《人工智能导论》课程项目指南中的**题目7：自然语言处理**，包含两个子任务：

1. **文本分类**：将输入文本自动划分到预定义的类别；
2. **方面级情感分析（ABSA）**：抽取评论文本中的方面词，并判断每个方面对应的情感极性（积极 / 中性 / 消极）。

项目以 **BERT 系列预训练模型微调**为主线，以 TF-IDF+SVM、TextCNN、BiLSTM 等经典方法为基线，构建统一的文本情感分析系统，详见开题报告（`docs/`）。
