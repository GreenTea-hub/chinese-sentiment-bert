## 二、选题背景与意义

随着电子商务、社交网络与在线评价平台的迅猛发展，网络中积累了海量的评论文本，如商品评论、餐饮点评、影视评论、课程评价等。这些文本蕴含着用户对产品、服务与内容的主观态度，如何自动、高效地从海量文本中提取情感信息，已成为舆情监控、商业决策与信息推荐等领域的关键需求。**文本情感分析**（又称意见挖掘，Opinion Mining / Sentiment Analysis）正是针对这一需求的核心技术：它通过自然语言处理与机器学习方法，自动判断一段文本所表达的情感倾向（积极 / 中性 / 消极）。

在实际应用中，仅判断整段文本的整体情感往往不够。以一句评论 “great food but the service was dreadful!” 为例，若考虑的对象是“食物”，情感是正面的；若考虑的对象是“服务”，情感则是反面的。**方面级情感分析**（Aspect-Based Sentiment Analysis, ABSA）正是针对这一细粒度需求提出的任务：在抽取文本中具体方面词的同时，判断每个方面对应的情感极性，从而提供更完整、更深入的情感分析结果。

本项目的现实意义主要体现在：

1. **舆情监控与分析**：自动分析社交媒体、新闻评论的情感倾向，辅助政府与企业掌握舆情动态。
2. **商业决策与口碑分析**：对电商评论、餐饮点评进行情感分析，帮助商家了解产品/服务的优缺点，辅助改进与营销。
3. **教学相关应用（更契合课程要求）**：将系统应用于课程评教文本分析——自动归纳学生对课程内容、教学方法、作业安排、课堂氛围等方面的情感反馈，帮助教师及时发现教学中的亮点与不足，辅助教学改进。

本项目以“**中文文本情感分析系统**”为题目，核心任务为文本情感极性分类，并扩展实现方面级情感分析。任务难度适中、数据集丰富、可复现性强，且完整覆盖“数据—模型—实验—分析—系统封装”的研究流程，非常适合作为四人小组的课程项目。

## 三、国内外研究现状（文献综述）

### 3.1 基于情感词典与规则的方法

早期情感分析主要依赖人工构建的情感词典与规则。研究者利用情感词典（如英文的 WordNet-Affect、SentiWordNet，中文的知网 HowNet、台湾大学 NTUSD、大连理工大学情感词汇本体库）统计文本中情感词的情感分值，并结合否定词、程度副词等规则进行修正（Turney，2002）。此类方法无需标注数据、解释性强，但高度依赖词典覆盖度，难以处理网络新词、隐式情感、讽刺等复杂表达，跨领域泛化能力差。

### 3.2 基于传统机器学习的方法

Pang 等（2002）最早将机器学习方法引入电影评论的情感分类，采用“特征工程 + 分类器”的范式：以词袋（Bag-of-Words）、TF-IDF 等作为文本特征，使用朴素贝叶斯、支持向量机（SVM）、最大熵等分类器进行训练。与传统规则方法相比，机器学习方法无需人工撰写规则、可自动学习特征与类别间的映射，在当时取得了显著更好的效果，成为情感分析的主流范式之一（Pang & Lee，2008）。

### 3.3 基于深度学习的方法

词向量（Word2Vec，Mikolov 等，2013）的出现推动了深度学习在情感分析中的应用。Kim（2014）提出的 TextCNN 利用卷积神经网络捕捉局部 n-gram 特征，在多个情感分类任务上达到当时最优效果；循环神经网络（RNN/LSTM）及双向 LSTM 能够建模长距离语义依赖；注意力机制（Attention）进一步提升了模型对关键情感信息的关注能力。

在方面级情感分析方面：Tang 等（2016）提出目标相关 LSTM（TD-LSTM/TC-LSTM），将目标词信息融入序列建模；Wang 等（2016）提出 ATAE-LSTM，引入注意力机制使模型关注与目标方面相关的上下文；Ma 等（2017）提出交互注意力网络 IAN，分别建模目标与上下文并交互学习。上述方法在标准数据集 SemEval-2014 Task 4（Pontiki 等，2014）上取得了显著提升。

### 3.4 基于预训练语言模型的方法

2018 年以来，以 BERT（Devlin 等，2019）为代表的预训练语言模型通过大规模语料预训练 + 下游任务微调，在包括情感分析在内的绝大多数自然语言处理任务上刷新了最好成绩；RoBERTa（Liu 等，2019）以及面向中文的 BERT-wwm（Cui 等，2019）、ERNIE（Zhang 等，2019）等模型进一步提升了效果。Xu 等（2019）将 BERT 后训练引入评论文本与方面级情感分析，进一步提升了方面级情感分析的精度。Sun 等（2019）系统研究了 BERT 微调在文本分类任务上的调参策略，为实际应用提供了有效参考。

**现状小结**：目前中文文本情感分析的主流方案是“预训练语言模型（BERT 系列）微调”，研究热点包括模型压缩与轻量化、少样本与提示学习、以及基于大语言模型的零样本情感分析。对课程项目而言，实现情感词典规则方法、传统机器学习基线与深度模型、并对比预训练模型微调，即可完整覆盖该领域的主要技术路线。

### 3.5 研究现状小结

情感分析方法体系完整、开源实现丰富：中文情感词典（知网、大连理工情感词汇本体库等）与公开数据集（酒店评论、微博、电商评论等）唾手可得，TextCNN、BiLSTM 等深度模型与 BERT 系列预训练模型均有成熟开源实现，便于实现与对比。因此本项目以“预训练语言模型微调”为主线，以情感词典规则方法与经典机器学习/深度模型为基线，构建一个可用的中文文本情感分析系统，工作量与难度匹配四人小组的规模要求。

## 四、项目任务与目标

### 4.1 项目任务

1. **情感极性分类（核心任务）**：构建情感分类模型，对输入的中文评论文本自动判断其情感极性（积极 / 中性 / 消极），并输出置信度。
2. **方面级情感分析（扩展任务）**：对输入的评论文本，自动抽取其中涉及的方面词，并判断每个方面词对应的情感极性，输出（方面词，情感极性）结构化结果。
3. **系统集成**：将上述能力封装为统一的命令行工具与简单可视化演示界面（Web 页面），实现端到端使用。

### 4.2 系统输入与输出

| 功能 | 输入 | 输出 |
| --- | --- | --- |
| 情感极性分类 | 一段中文评论文本 | 情感极性标签（积极 / 中性 / 消极）及概率分布 |
| 方面级情感分析 | 一句或一段评论文本（可含多个方面） | （方面词，情感极性）列表，例如 [("食物", 积极), ("服务", 消极)] |
| 系统整体 | 文本文件或交互输入 | 结构化结果（JSON）+ 可视化展示 |

### 4.3 评价指标

- **情感极性分类**：准确率（Accuracy）、宏平均精确率（Macro-Precision）、宏平均召回率（Macro-Recall）、宏平均 F1（Macro-F1）、混淆矩阵；同时记录推理时间以衡量效率。
- **方面级情感分析**：
  - 方面抽取：抽取的精确率、召回率与 F1（ATE-F1）；
  - 方面情感分类：情感分类准确率（Accuracy）；
  - 综合指标：方面级 F1（Aspect-level F1，要求方面抽取正确且极性判断正确）。
- 对两种任务均记录模型大小与单条推理耗时，兼顾效果与效率。

## 六、初步技术方案

### 6.1 总体架构

1. **数据处理层**：文本清洗、中文分词（jieba）或 BERT 子词分词、情感极性标签映射、数据集划分；
2. **表示层**：以预训练语言模型（BERT / BERT-wwm / RoBERTa-wwm-ext，中文）编码文本，得到上下文相关表示；
3. **情感分类头**：取 [CLS] 表示，接全连接层与 Softmax 输出情感极性概率；
4. **ABSA 模块（扩展）**：方面抽取采用 BIO 序列标注（或 span 抽取），情感分类采用方面感知注意力 / 方面位置嵌入，二者可联合训练；
5. **推理与封装层**：基于 HuggingFace Transformers 封装 pipeline，用 Flask/Gradio 构建演示界面。

### 6.2 基线方法

- **情感词典规则法**：基于中文情感词典（如知网 HowNet、大连理工情感词汇本体库）统计情感分值，结合否定词与程度副词规则判断极性。
- **TF-IDF + SVM**：以 TF-IDF 为特征、SVM 为分类器，作为传统机器学习基线。
- **TextCNN**：基于卷积神经网络的情感分类基线（Kim，2014）。
- **BiLSTM**：基于双向循环神经网络的情感分类基线。

### 6.3 主模型

BERT 系列预训练模型微调，参考 Sun 等（2019）的调参经验（学习率、batch size、最大序列长度等），并比较 bert-base-chinese、BERT-wwm、RoBERTa-wwm-ext 等中文预训练模型的情感分类效果。

### 6.4 方面级情感分析模块（扩展）

- **基线方法**：TD-LSTM；ATAE-LSTM。
- **主模型**：BERT-based 联合模型（方面抽取 + 方面情感分类），或 BERT + 方面感知注意力模型。
- **重点验证**：模型对同一句中多个方面情感极性相反（如 “great food but the service was dreadful!”）与隐式方面的处理能力。

### 6.5 候选算法对比与选型

| 方法 | 优点 | 缺点 | 适用环节 |
| --- | --- | --- | --- |
| 情感词典规则法 | 无需标注数据、可解释 | 依赖词典覆盖，难处理新词与复杂表达 | 基线 / 冷启动 |
| TF-IDF + SVM | 简单、训练快、可解释 | 依赖特征工程，忽略词序与语义 | 机器学习基线 |
| TextCNN | 捕捉局部 n-gram 特征、训练快 | 长距离依赖建模弱 | 深度学习基线 |
| BiLSTM | 建模序列双向语义 | 训练较慢、并行性差 | 深度学习基线 |
| BERT / RoBERTa 系列 | 语义表示强、微调即可达到 SOTA、中文生态好 | 模型大、推理慢、需 GPU | 主模型（分类 + ABSA） |

**选型结论**：以 BERT 系列预训练模型为主模型，原因在于其效果领先、有成熟中文预训练权重、HuggingFace 生态完善、且与课程“人工智能导论”的知识体系衔接自然。

## 七、实验方案（初步）

1. **实验环境**：Python 3.x、PyTorch、HuggingFace Transformers、scikit-learn、jieba、matplotlib；优先使用 GPU（实验室或本地单卡），CPU 可运行基线模型。
2. **实验流程**：
   - 数据准备与预处理，统计类别分布与样本长度分布；
   - 实现并跑通基线模型（情感词典规则法、TF-IDF+SVM、TextCNN、BiLSTM）；
   - 实现主模型（预训练模型微调），进行超参数调优（学习率、训练轮数、batch size、最大长度、dropout）；
   - 消融与对比实验：不同预训练模型对比、有无方面信息对比、联合训练与流水线对比；
   - 结果可视化与误差分析：混淆矩阵、PR 曲线、训练/验证曲线、典型错误样本分析。
3. **结果呈现**：以表格汇总指标、以图表展示实验结果，并进行定性的分析与说明。
