## 一、项目概述

本项目为《人工智能导论》课程项目指南题目7（自然语言处理·情感分析方向），核心任务为中文文本情感极性分类（积极 / 消极），扩展任务为方面级情感分析（ABSA：抽取方面词并判断每个方面的情感极性），最终封装为可交互演示系统。

技术路线以 **BERT 系列预训练模型微调为主线**，以情感词典规则法、TF-IDF+SVM、TextCNN、BiLSTM 为基线，构建完整对比实验（详见开题报告）。

## 三、实验结果

### 3.1 情感极性分类（测试集）

**中文酒店评论（ChnSentiCorp，777 条测试）**

| 方法 | Accuracy | Macro-F1 | 说明 |
| --- | --- | --- | --- |
| 情感词典规则法 | 判定样本 0.611 | 0.587 | 判定覆盖率 6.95%（内置精简词典） |
| TF-IDF + SVM | 0.870 | 0.856 | jieba 分词 + 1-2gram |
| TextCNN | 0.785 | 0.712 | |
| BiLSTM | 0.794 | 0.741 | |
| **BERT 微调（bert-base-chinese）** | **0.888** | **0.873** | 主模型，最优 |

**微博情感（weibo_senti_100k，19,988 条官方测试）**

| 方法 | Accuracy | Macro-F1 |
| --- | --- | --- |
| 情感词典规则法 | 判定样本 0.593 | 0.536（覆盖率 7.42%） |
| TF-IDF + SVM | 0.966 | 0.966 |
| TextCNN | 0.981 | 0.981 |
| BiLSTM | 0.978 | 0.978 |
| BERT 微调 | 0.976 | 0.976 |

**分析**：
- ChnSentiCorp 上 BERT 明显领先（0.888 vs SVM 0.870，尤其在 Macro-F1 上 +0.017），体现预训练模型在短文本语义理解上的优势；
- weibo 任务整体难度低（微博情感表达直白），TextCNN 以 0.981 略优于 BERT（0.976），与文献中"简单任务上轻量模型不输大模型"的观察一致；
- 词典法覆盖低（<8%）但判定样本准确率 ~0.6，作为冷启动基线具有参考价值。

### 3.2 方面级情感分析（SemEval-2014，联合训练模型）

| 领域 | ATE-F1（方面抽取） | Aspect-level F1（抽取+情感） |
| --- | --- | --- |
| Restaurant | 0.624 | 0.624 |
| Laptop | 0.433 | 0.433 |

- 联合训练：BERT 共享编码，BIO 序列标注头 + 方面情感头（4 极性：positive/negative/neutral/conflict），多任务损失联合优化；
- 模型成功处理"同一句多方面相反情感"场景，如 *"The food is great but the service was horrible"* → food(积极) + service(消极)；
- 说明：官方测试集（PhaseA/PhaseB）在本仓库中缺少 polarity 标注，评测采用训练集 8:2 划分（与报告数据划分策略一致）。

## 四、系统演示（Flask Web 界面）

- `src/app.py`：单页 HTML + `/analyze` JSON 接口，浏览器输入文本即得整体情感（置信度）与方面级结果；
- 端到端验证示例：输入 "The food is great but the service was horrible." →
  `整体情感: 积极(0.66)`、`方面: food(积极), service(消极)`；
- 中文输入走 BERT 分类模型，英文输入走 ABSA 联合模型（ABSA 数据为英文 SemEval-2014）。

## 五、遇到的问题与解决

| 问题 | 解决 |
| --- | --- |
| HuggingFace 直连超时 | 改用 hf-mirror.com 镜像下载权重并本地缓存，训练时离线模式（`HF_HUB_OFFLINE=1`） |
| ABSA 官方测试集缺 polarity 标注 | 采用训练集 8:2 划分评测 |
| ABSA 序列标注类别不平衡导致抽取全空 | B/I 类别加权（10/10/1）修复，ATE-F1 从 0 → 0.62 |
