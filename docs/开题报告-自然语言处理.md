## 二、选题背景与意义

随着互联网与移动应用的快速发展，网络中的非结构化文本数据呈爆炸式增长。新闻、评论、邮件、论坛帖子以及教学反馈等海量文本，仅靠人工阅读与整理已经难以应对。文本分类是文本信息处理的基础，也是自然语言处理（NLP）领域一项重要的研究课题，其核心任务是将文本按照内容自动划分到相关的主题类别中，从而把杂乱无章的文本组织起来，帮助用户快速、准确地定位所需信息。文本分类技术已广泛应用于邮件分类、信息过滤、垃圾网页判定、文本语料库构建与信息检索等领域。

然而，仅仅知道文本“属于哪一类”在很多场景下还不够。以商品评论和课程评价为例，一段评论往往同时涉及多个对象（方面），例如 “great food but the service was dreadful!” 这句评论中，若考虑的方面是“食物”，情感是正面的；若考虑的方面是“服务”，情感则是反面的。方面级情感分析（Aspect-Based Sentiment Analysis, ABSA）正是针对这一细粒度需求提出的任务：在抽取文本中具体方面词的同时，判断每个方面对应的情感极性，从而提供更完整、更深入的情感分析结果。

本项目的现实意义主要体现在：

1. **信息组织与检索**：实现新闻/邮件/网页的自动分类，帮助用户高效定位信息，判定垃圾网页与不当内容。
2. **舆情与评论分析**：对电商评论、餐饮评论等进行细粒度情感分析，帮助商家与平台了解产品/服务的优缺点。
3. **教学相关应用（更契合课程要求）**：将系统应用于课程评教文本分析——自动归纳学生对课程内容、教学方法、作业安排、课堂氛围等方面的反馈及情感倾向，帮助教师及时发现教学中的亮点与不足，辅助教学改进；也可用于学生论坛帖子、作业文本的自动归类，辅助教学管理。

本项目选题为教师提供的“自然语言处理”题目，包含文本分类与方面级情感分析两个子任务。两子任务共享自然语言处理核心技术（文本表示、深度学习、预训练模型），既能体现完整的“数据—模型—实验—分析”研究流程，又具有适中的难度与工作量，非常适合作为四人小组的课程项目。

## 三、国内外研究现状（文献综述）

### 3.1 文本分类研究现状

文本分类经历了三个阶段的发展：

1. **基于知识工程的规则方法**：早期文本分类主要依靠人工定义规则（如关键词、模板）进行分类，分类精度依赖专家经验，人工成本高、难以适应大规模文本。
2. **传统机器学习方法**：随着数据挖掘与机器学习研究的兴起，研究者开始采用“特征工程 + 分类器”的范式，即先用 TF-IDF、词袋（Bag-of-Words）等表示文本，再用朴素贝叶斯、支持向量机（SVM）、逻辑回归等分类器进行训练与预测。这类方法无需专家干预、可适应多个领域，是至今仍在使用的主流基线方法。
3. **深度学习与预训练语言模型方法**：词向量（Word2Vec、GloVe）的出现推动了深度学习在文本分类中的应用。Kim（2014）提出的 TextCNN 利用卷积神经网络捕捉局部 n-gram 特征；Lai 等（2015）提出 RCNN 结合循环网络与卷积；Joulin 等（2017）提出的 FastText 以极低开销取得不错的分类效果；Yang 等（2016）提出层次注意力网络 HAN，用于文档级分类。2018 年以来，以 BERT（Devlin 等，2019）为代表的预训练语言模型通过大规模语料预训练 + 下游任务微调，在绝大多数文本分类基准上刷新了最好成绩；RoBERTa（Liu 等，2019）、以及面向中文的 BERT-wwm（Cui 等，2019）、ERNIE（Zhang 等，2019）等模型进一步提升了效果。

**现状小结**：目前文本分类的主流方案是“预训练语言模型微调”，研究热点转向模型压缩、少样本学习与基于大语言模型的提示学习。对课程项目而言，实现传统机器学习基线与深度模型、并对比预训练模型微调，即可完整覆盖该领域的主要技术路线。

### 3.2 方面级情感分析研究现状

方面级情感分析（ABSA）包含两个子任务：**方面词抽取**（Aspect Term Extraction, ATE）与**方面情感分类**（Aspect Sentiment Classification, ASC）。其研究脉络如下：

1. **基于词典与规则的早期方法**：利用情感词典、句法规则判断情感极性，方法简单但覆盖面有限、跨领域泛化能力差。
2. **基于特征工程的机器学习方法**：采用 SVM、CRF 等模型，结合词性、句法依存等特征进行方面抽取与情感分类，性能优于纯规则方法。
3. **深度学习方法**：Tang 等（2016）提出目标相关 LSTM（TD-LSTM/TC-LSTM），将目标词信息融入序列建模；Wang 等（2016）提出 ATAE-LSTM，引入注意力机制使模型关注与目标方面相关的上下文；Ma 等（2017）提出交互注意力网络 IAN，分别建模目标与上下文并交互学习。上述方法均在标准数据集 SemEval-2014 Task 4（Pontiki 等，2014）上取得了显著提升。
4. **联合建模与预训练模型方法**：Li 等（2019）提出方面抽取与情感预测的统一模型，实现端到端训练；Xu 等（2019）将 BERT 后训练引入评论文本与 ABSA，进一步提升了方面级情感分析的精度。近年来，基于生成式大语言模型（如以 BART、T5、ChatGPT 为底座）的抽取与提示方法成为新的研究热点。

**难点与挑战**：方面级情感分析的难点包括隐式方面（未在句中出现但隐含的方面）、同一句多个方面情感极性相反（如 “great food but the service was dreadful!”）、否定与模糊表达、跨领域迁移等。本项目将重点验证模型在上述场景下的表现。

### 3.3 研究现状小结

现有方法体系完整、开源实现丰富：文本分类与 ABSA 均有成熟的传统基线（TF-IDF+SVM、词典方法）与深度模型（TextCNN、BiLSTM、TD-LSTM、ATAE-LSTM），且两类任务均可统一到预训练语言模型（BERT 系列）框架下，便于实现与对比。因此本项目以“预训练语言模型微调”为主线，以传统方法与早期深度模型为基线，构建文本分类 + 方面级情感分析一体化系统，工作量与难度匹配四人小组的规模要求。

## 四、项目任务与目标

### 4.1 项目任务

1. **文本分类子任务**：构建文本分类模型，将输入的文本自动划分到预定义的类别（如新闻主题类别），输出类别标签及置信度。
2. **方面级情感分析子任务**：对输入的评论文本，自动抽取其中涉及的方面词，并判断每个方面词对应的情感极性（积极 / 中性 / 消极）。
3. **系统集成**：将两个子任务封装为统一的命令行工具与简单可视化演示界面（Web 页面），实现端到端使用。

### 4.2 系统输入与输出

| 子任务 | 输入 | 输出 |
| --- | --- | --- |
| 文本分类 | 一段自然语言文本（如新闻标题/正文） | 所属类别标签及其概率分布 |
| 方面级情感分析 | 一句或一段评论文本（可含多个方面） | （方面词，情感极性）列表，例如 [("food", 积极), ("service", 消极)] |
| 系统整体 | 文本文件或交互输入 | 结构化结果（JSON）+ 可视化展示 |

### 4.3 评价指标

- **文本分类**：准确率（Accuracy）、宏平均精确率（Macro-Precision）、宏平均召回率（Macro-Recall）、宏平均 F1（Macro-F1）、混淆矩阵；同时记录推理时间以衡量效率。
- **方面级情感分析**：
  - 方面抽取：抽取的精确率、召回率与 F1（ATE-F1）；
  - 方面情感分类：情感分类准确率（Accuracy）；
  - 综合指标：方面级 F1（Aspect-level F1，要求方面抽取正确且极性判断正确）。
- 对两种任务均记录模型大小与单条推理耗时，兼顾效果与效率。

## 六、初步技术方案

### 6.1 总体架构

采用“统一预训练模型底座 + 双任务头”的架构：

1. **数据处理层**：文本清洗、中文分词（jieba）或 BERT 子词分词、标签映射、数据集划分；
2. **表示层**：以预训练语言模型（BERT / BERT-wwm / RoBERTa-wwm-ext，中文）编码文本，得到上下文相关表示；
3. **文本分类头**：取 [CLS] 表示，接全连接层与 Softmax 输出类别概率；
4. **ABSA 模块**：方面抽取采用 BIO 序列标注（或 span 抽取），情感分类采用方面感知注意力 / 方面位置嵌入，二者可联合训练；
5. **推理与封装层**：基于 HuggingFace Transformers 封装 pipeline，用 Flask/Gradio 构建演示界面。

### 6.2 文本分类模块

- **基线方法**：TF-IDF + SVM / 逻辑回归；FastText；TextCNN；BiLSTM。
- **主模型**：BERT 微调，参考 Sun 等（2019）的调参经验（学习率、batch size、最大序列长度等）。
- **模型对比**：比较 bert-base-chinese、BERT-wwm、RoBERTa-wwm-ext 等中文预训练模型的分类效果。

### 6.3 方面级情感分析模块

- **基线方法**：基于情感词典的规则方法；TD-LSTM；ATAE-LSTM。
- **主模型**：BERT-based 联合模型（方面抽取 + 方面情感分类），或 BERT + 方面感知注意力模型。
- **重点验证**：模型对同一句中多个方面情感极性相反（如 “great food but the service was dreadful!”）与隐式方面的处理能力。

### 6.4 候选算法对比与选型

| 方法 | 优点 | 缺点 | 适用环节 |
| --- | --- | --- | --- |
| TF-IDF + SVM | 简单、训练快、可解释 | 依赖特征工程，忽略词序与语义 | 文本分类基线 |
| TextCNN | 捕捉局部 n-gram 特征、训练快 | 长距离依赖建模弱 | 文本分类基线 |
| BiLSTM | 建模序列双向语义 | 训练较慢、并行性差 | 文本分类基线 |
| BERT / RoBERTa 系列 | 语义表示强、微调即可达到 SOTA、中文生态好 | 模型大、推理慢、需 GPU | 文本分类 + ABSA 主模型 |

**选型结论**：以 BERT 系列预训练模型为两个子任务的统一主模型，原因在于其效果领先、有成熟中文预训练权重、HuggingFace 生态完善、且与课程“人工智能导论”的知识体系衔接自然。

## 七、实验方案（初步）

1. **实验环境**：Python 3.x、PyTorch、HuggingFace Transformers、scikit-learn、jieba、matplotlib；优先使用 GPU（实验室或本地单卡），CPU 可运行基线模型。
2. **实验流程**：
   - 数据准备与预处理，统计类别分布与样本长度分布；
   - 实现并跑通基线模型（传统机器学习 + 早期深度模型）；
   - 实现主模型（预训练模型微调），进行超参数调优（学习率、训练轮数、batch size、最大长度、dropout）；
   - 消融与对比实验：不同预训练模型对比、有无方面信息对比、联合训练与流水线对比；
   - 结果可视化与误差分析：混淆矩阵、PR 曲线、训练/验证曲线、典型错误样本分析。
3. **结果呈现**：以表格汇总指标、以图表展示实验结果，并进行定性的分析与说明。
